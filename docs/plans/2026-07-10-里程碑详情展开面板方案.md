# 里程碑详情展开面板方案

## 1. 需求背景

当前静态评估看板的中列里程碑图只在 SVG 节点内展示截断摘要。对于包含多条或较长 `constraints` 的 milestone，用户无法看清具体约束内容。右列评估阶段已经提供 `<details>/<summary>` 展开式详情，本次改动沿用该交互，让用户点击 milestone 后能在中列直接阅读完整要求。

## 2. 修改范围

- 修改 `display/index.html`：在里程碑图下方增加一个默认展开的 milestone 详情卡。
- 修改 `tests/test_display_index_static.py`：补充静态断言，确保详情卡、约束详情和匹配诊断入口不会被误删。
- 不修改 `display/build.py` 的数据结构；当前 `scenario.milestone_graph.nodes[].constraints` 已经包含展示所需字段。

## 3. 实现方案

1. 在 `renderGraph()` 中绘制 SVG 后追加 `milestoneDetailCard(scenario)`。
2. `milestoneDetailCard()` 根据 `state.selectedMilestoneId` 查找当前节点；未选择时展示提示，选择后默认展开并显示基础信息。
3. 详情卡复用现有 `detailBlock()` 风格，分组展示：
   - 阶段目标：来自 `stageDefinitionForMilestone()`。
   - milestone 描述：来自 graph node 的 `description`。
   - 约束定义：完整列出 `constraint_id`、`target`、`namespace`、`operator`、`threshold`、`hard`、`evaluator_hint`、`expected_summary`。
   - 匹配诊断：来自 `milestoneMatchingFor()`，展示边界、匹配分数和 constraint_scores。
4. 保留 SVG 节点内的短摘要，用于图上快速扫视；完整内容只在详情卡里展示，避免图布局膨胀。

## 4. 验收方式

- 运行 `python -m pytest tests/test_display_index_static.py tests/test_display_build.py -q`。
- 若环境允许，再运行 `python -m pytest -q` 做全量回归。
- 手动检查 `display/index.html`：点击 milestone 后，中列下方出现可展开详情，长约束不再被截断在 SVG 节点内。

## 附录A. 项目中没有把握实现的模块部分

本次改动对数据结构与评估流程没有不确定模块。唯一需要现场验证的是不同真实 adapted case 中 constraint 字段是否都足够完整；若字段缺失，前端会以“无”展示，避免阻断页面渲染。
