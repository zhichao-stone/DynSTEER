# 实验结果路径输出清理方案

## 1. 问题与目标

实验结束后，`main.py` 会遍历本次运行产生的全部 case，并把每个 case 的结果标识或文件路径逐行打印到终端。大规模实验因此产生大量低价值输出并刷屏。

本次修改目标是停止逐项打印这些路径类信息，同时保留现有完成数量日志，使用户仍能确认实验、数据适配或 benchmark 评估已经完成。

## 2. 修改范围

修改 `main.py` 中三个成功分支：

1. 统一实验 `--exp`：删除遍历 `results` 并打印 `benchmark/method/model/case` 的逻辑。
2. `--only-adapt`：删除遍历 `adapted_paths` 并打印适配文件路径的逻辑。
3. 单 benchmark harness：删除遍历 `outputs` 并打印报告文件路径的逻辑。

以上分支继续保留包含结果数量的结构化完成日志；结果文件的生成、缓存和返回值均不改变。

## 3. 验证方式

1. 对 `main.py` 执行 Python 编译检查，确认修改无语法错误。
2. 搜索成功分支，确认不存在逐项 `print` 路径或 case 标识的残留逻辑。
3. 检查 Git 差异，确认仅修改 CLI 展示行为与本方案文档，不影响实验执行及结果写入。

## 4. 约束检查

- 方案直接删除冗余输出，不增加开关、封装函数或兼容层。
- 保留关键完成日志，符合避免终端刷屏的日志约束。
- 不修改核心接口、输出目录结构或实验结果内容，因此无需新增 API 文档。
- 不执行 Git 提交。

## 附录A. 项目中没有把握实现的模块部分

无。本次问题来源和修改边界已由 `main.py` 的成功分支明确定位，不涉及不确定模块。
