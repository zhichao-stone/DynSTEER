# tqdm进度条case序号显示方案

## 1. 需求目标

在每个 case 的进度条标题行中，于 `case_id` 左侧显示 `# Test Case {idx}`，让终端可以直接看出当前正在执行第几个 case。

## 2. 实现方案

- 采用原始任务顺序作为 `idx`，从 1 开始计数。
- 扩展 `TqdmCaseProgressManager.case_started()`，允许传入 `case_index`。
- 在串行和并行调度启动 case 时传入 `task.order + 1`。
- 标题行格式由原来的 `{case_id}` 调整为 `# Test Case {idx} {case_id}`；未传序号时保留原有 `{case_id}`，避免内部自动创建进度条时缺少上下文导致异常。

## 3. 测试方案

- 新增 pytest 单元测试，使用假的 tqdm factory 捕获标题行 `bar_format`。
- 先验证未实现时标题行没有序号的失败场景。
- 实现后验证传入 `case_index=3` 时标题行为 `# Test Case 3 alpha_case`，并确认 `{}` 字符仍会被转义。

## 附录A. 项目中没有把握实现的模块部分

本次修改集中在进度条标题渲染和调度器启动参数传递，未涉及外部 benchmark 环境、LLM 调用或真实终端宽度控制。没有明显无法把握的模块；真实 tqdm 在不同终端宽度下的截断行为需要实际运行时观察，但本需求只修改标题内容来源。
