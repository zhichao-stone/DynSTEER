# 论文插图 PPT 复现配置

本文档对应 `docs/paper/iclr2027/figures/` 中的两张插图：

- `overall-framework.png` / `overall-framework.svg`
- `teaser_comparison.png` / `teaser_comparison.svg`

两张图都不是照片型插图，全部由圆角矩形、圆形节点、直线/曲线箭头、文本框和少量 Unicode 符号组成。PPT 复现时建议直接使用“插入形状 + 文本框”，不要使用图片描摹或主题 SmartArt。

## 1. 画布与坐标

SVG 使用左上角为原点的像素坐标。PPT 中建议按 `1 px = 0.01 inch = 0.72 pt` 建立画布，这样 SVG 坐标可直接换算。

| 图 | SVG 尺寸 | PPT 自定义幻灯片尺寸 | 宽高 |
|---|---:|---:|---:|
| `overall-framework` | `1440 x 760` | `14.4 x 7.6 in` | `36.58 x 19.30 cm` |
| `teaser_comparison` | `1400 x 575` | `14.0 x 5.75 in` | `35.56 x 14.61 cm` |

建议为每个文件单独使用上述自定义尺寸。如果必须放进同一个 16:9 演示文稿，可先按原尺寸绘制后成组，再统一缩放到页面宽度；不要按宽高分别拉伸，否则圆角和箭头会变形。

形状的“位置”均指左上角坐标，单位为 SVG px。例如 `x=40, y=16, w=1360, h=325` 在 overall 图中对应 PPT 的左上角 `0.40 in, 0.16 in`，宽高 `13.60 in, 3.25 in`。

字体与字号：

- 字体：`Segoe UI`。若需要兼容更多系统，可替换为 Arial，但视觉密度会略降。
- SVG 中 `font-weight: 700/800/900` 在 PPT 中统一使用 Bold。
- SVG 字号是像素值，按 `1 px = 0.72 pt` 换算：`9 px = 6.48 pt`，`10 px = 7.2 pt`，`11 px = 7.92 pt`，`12 px = 8.64 pt`，`13 px = 9.36 pt`，`15 px = 10.8 pt`。
- 文本框建议关闭自动缩放，内部边距设为 `0` 或很小的固定值。

## 3. 线条、箭头与阴影

PPT 中优先使用“直线连接符”和“曲线连接符”。将形状附着到卡片或圆点后再改线色、线宽和箭头。

| SVG 配置 | PPT 配置 |
|---|---|
| `stroke-width: 1` | `0.75-1.0 pt` |
| `stroke-width: 1.2` | `1.0 pt` |
| `stroke-width: 1.5` | `1.1 pt` |
| `stroke-width: 2` | `1.4 pt` |
| `stroke-width: 2.5` | `1.8 pt` |
| `stroke-width: 3` | `2.2 pt` |
| `stroke-dasharray: 3,3` | 短划线，约 `0.03 in` 线段 / `0.03 in` 间隔 |
| `stroke-dasharray: 4,3` | 短划线，约 `0.04 in` 线段 / `0.03 in` 间隔 |
| `stroke-dasharray: 4,4` | 短划线，约 `0.04 in` 线段 / `0.04 in` 间隔 |

箭头样式：

- 使用“实心三角 / Stealth Arrow”。
- 箭头颜色必须与线色相同。
- 主流程箭头：线宽约 `1.4-1.8 pt`，箭头长度 `0.10-0.12 in`，宽度 `0.08-0.10 in`。
- 局部小箭头：线宽约 `1.1 pt`，箭头长度 `0.08 in`，宽度 `0.06 in`。
- overall 图底部左右两条绿色连接线在 SVG 中引用了未定义的 `arr-emerald`，因此渲染结果是没有箭头的短线。若要严格复现，使用无线头绿色短线；若只追求语义清晰，可改为绿色箭头。

阴影：

- SVG 阴影为 `#0F172A`，透明度约 `94%`。
- PPT 中可选：角度 `90°`，距离 `0.04 in`，模糊 `0.08-0.12 in`，颜色 `#0F172A`，透明度 `94%`。
- 只给左右两大外层面板加阴影，内部卡片不加。

| 状态节点 | 椭圆 | 直径 `0.28-0.32 in`，圆心对齐文字 |
| 进度条 | 圆角矩形 | 高度 `0.18 in`，圆角半径 `0.06 in` |
| 序号徽章 | 椭圆 | 直径 `0.22-0.24 in`，白色 Bold 数字居中 |
| 箭头标签 | 圆角矩形 + 文本框 | 高度 `0.13-0.16 in`，圆角半径 `0.03 in` |

推荐绘制顺序：

1. 先画左右或上下两大外层面板。
2. 画标题栏、序号徽章和标题文本。
3. 画内容卡片、小信息条、进度条。
4. 画圆点和直线/曲线连接线。
5. 最后补 Unicode 符号和所有小标签。
6. 按语义分组，例如每个外层面板一组、每个子卡片一组。

如果希望彩色 emoji 更稳定，可使用 Windows 系统自带的 `Segoe UI Emoji`。如果希望论文风更干净，可用 Microsoft 365 内置图标替代：

1. PPT 菜单：`插入 > 图标`。

3. 插入后将其改为单色填充，与所在文本色保持一致。

论文正式版建议优先使用内置单色图标或继续使用 Unicode 符号；不要混用外部彩色剪贴画风格图标。

## 8. 可选：曲线的近似绘制法

原图中的 DAG 分支是二次贝塞尔曲线。PPT 手绘时不必精确复刻控制点，可这样近似：

1. 插入“曲线连接符”。
2. 点击起点和终点。
3. 拖动中点形成上弯或下弯，使曲线明显避开另一条分支。
4. 将线宽设为 `1.4 pt`，关闭阴影。
5. 添加对应颜色箭头。

如果使用支持贝塞尔编辑的工具，可先按 SVG 曲线控制点画，再导出为 EMF/SVG 后嵌入 PPT；但若目标是“完全用 PPT 原生形状重绘”，建议直接使用曲线连接符近似。
